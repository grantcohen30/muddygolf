# MuddyGolf

Jeff's 18Birdies rounds, hole by hole. Live at https://grantcohen30.github.io/muddygolf/

How it works (all free):
- Jeff forwards each 18Birdies scorecard email to the MuddyGolf alias.
- A Google Apps Script (runs as the owner's Google account) checks the alias every minute, stores new rounds in a Drive file, emails Jeff when the page updates, and serves the rounds as JSON.
- `index.html` fetches that JSON when opened, and `courses.json` (hole pars) from next to it. No build, no deploy per update.

Add or fix a course's pars: edit `courses.json` (one array of hole pars per course name, exactly as the page shows it) and push.

`index.html` and `courses.json` are generated by `tools/muddy_pages.py` in the golf-swing project. The Apps Script is kept privately and is not in this repo.
